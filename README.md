# Commands & Colors: Napoleonics (VASSAL module)

The standard-size (13 × 9 hex) VASSAL module for GMT Games' *Commands & Colors: Napoleonics*.

* `dist/` is the module, unpacked: one commit per release, tagged `v<version>`, taken from the [Vassal Module Library](https://vassalengine.org/library/projects/Commands__Colors_Napoleonics), with that version's change-log section as the commit message.
* Branches:
  * `main`: Version 5 (5.0.0 onwards; 5.1 in active support);
  * `v4`: 4.0.6 → 4.1.16 → 4.2.x (4.2 in active support);
  * `v3`: 3.0 → 3.43;
  * `dev`: development builds and unreleased betas;
  * `pc-alpha`: Point & Click movement fixes (see issue #504).
* Build with `./mvnw package` (module written to `target/`).
* Report problems with an issue here, or from the module's Help menu.

The Epic & Grand Battles module is in [ccnapoleonicsEpic](https://github.com/RiverWanderer-Vassal/ccnapoleonicsEpic).
